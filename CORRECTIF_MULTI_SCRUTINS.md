# Correctif multi-scrutins

Ce correctif restaure l'interface complète de gestion des scrutins sans supprimer les fonctionnalités du patch UX/UI.

Fonctions restaurées :
- affichage de tous les scrutins existants ;
- création d'un scrutin TEST ou OFFICIEL ;
- activation d'un scrutin existant ;
- suppression d'un scrutin TEST non actif ;
- modification du titre ;
- gestion des électeurs ;
- gestion des candidats ;
- import Excel ;
- anciens exports PDF/CSV.

Fonctions conservées :
- suspension et reprise ;
- liste des votants ;
- annulation et réautorisation ;
- journal d'audit ;
- dashboard enrichi ;
- export Excel ;
- PDF professionnel.

Aucune donnée Firestore n'est supprimée par ce correctif.
